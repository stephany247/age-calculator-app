# Age Calculator App

A responsive age calculator built with plain HTML, CSS, and JavaScript.

## Run it

1. Download and extract the project.
2. Open `index.html` in your browser.
3. Enter a date of birth and press the purple arrow button.

No build tools or package installation are required.

## Features

- Calculates age in years, months, and days.
- Validates required fields, day/month ranges, future dates, and impossible calendar dates.
- Responsive desktop and mobile layouts.
- Hover and keyboard-focus states.
- Animated result numbers, with support for reduced-motion preferences.
- Accessible labels and live error/result announcements.

## Files

- `index.html` — structure and form fields
- `style.css` — layout, responsive styles, and interactive states
- `script.js` — validation, age calculation, and number animation
